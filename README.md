# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 坝区断网时填写离线复核单，回连后按异常当前版本批量合并：先到先收，后到的不同改法登记待核对冲突。
- 重大异常存在未决冲突时，不能送负责人审批或关闭；引用读数订正后，未批准结论失效并需重新确认。
- 批次写入失败可从断点恢复，只补未写完的复核项；重复上传不产生新审计记录。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，订正生成新读数并保留原读数，所有修订形成独立版本和审计时间线。
- 异常处置页、审计页与JSON审阅包均展示批次来源、冲突结果和重新确认状态。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
