# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- **离线复核单与按字段合并**：坝区断网时把观察、证据、评估、处置建议登记为离线批次（可含多个班组）；回连后按异常当前版本合并——同一字段先到的直接采纳，后到的不同改法挂起“待核对”，不覆盖当前值。
- **冲突核对与会签阻断**：冲突可“保留先到/采用后到”；重大异常存在未决冲突前不能送负责人审批或关闭，页面直接显示阻断原因。
- **引用读数与重新确认**：新读数写入后，尚未批准的复核结论与处置方案草案立即失效（待重新确认），审批退回；基于最新读数重新确认后方可继续。
- **断点恢复与幂等**：写入失败的批次从断点恢复，只补未写完的复核项；重复上传（含仅冲突项）不产生重复审计记录。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- **异常处置页、审计页、JSON审阅包**统一展示批次来源、冲突结果和重新确认状态。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
